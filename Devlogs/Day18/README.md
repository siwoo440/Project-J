# Project J 개발 일지

## 18일차 : 지상 이동 가속·감속 및 빠른 방향 전환 구현

### 개발 목표

플레이어의 지상 이동에 자연스러운 가속과 감속을 적용하고, 진행 방향과 반대되는 입력이 들어왔을 때 빠르게 정지한 뒤 새 방향으로 전환되도록 개선했다.

### 주요 구현 내용

#### 1. 지상 이동 계산 분리

- 지상 수평 속도 계산을 `PlayerGroundMovementSolver`로 분리했다.
- 현재 속도와 목표 속도를 비교해 이동 상태에 맞는 가속도를 선택하도록 구성했다.
- 프레임 시간에 따라 속도가 일정하게 변하도록 `Vector3.MoveTowards` 기반 계산을 적용했다.

#### 2. 일반 이동 가속

- 정지 상태에서 이동 입력 시 최고 속도로 즉시 바뀌지 않고 부드럽게 가속하도록 구현했다.
- 걷기와 달리기에 서로 다른 가속도를 적용했다.
- 기존 플레이어 데이터 에셋의 이동 수치를 그대로 사용하도록 유지했다.

#### 3. 입력 해제 감속

- 이동 입력을 놓으면 현재 수평 속도가 감속도를 기준으로 0까지 감소하도록 구현했다.
- 즉시 정지와 과도한 미끄러짐을 피하면서 짧고 자연스러운 정지감을 유지했다.

#### 4. 빠른 방향 전환

- 현재 이동 방향과 새 목표 방향의 내적을 이용해 반대 방향 입력을 감지하도록 구현했다.
- 두 방향의 각도가 90도보다 클 때 방향 전환 상태로 판정한다.
- 방향 전환 중에는 기본 가속도와 감속도를 합산해 빠르게 정지하고 새 방향으로 재가속하도록 구성했다.
- 걷기와 달리기에서 각각 알맞은 방향 전환 가속도를 사용한다.

#### 5. 기존 이동 기능 유지

- 공중 이동은 기존 공중 가속도 계산을 유지했다.
- 점프, 코요테 타임, 점프 입력 버퍼 기능을 유지했다.
- 달리기와 스태미나 소모·회복 기능을 유지했다.
- 앉기, 천장 감지, 외부 힘과 밀치기 기능을 유지했다.
- 카메라 기준 이동과 캐릭터 회전 기능을 유지했다.

#### 6. 로그 체계 통일

- 이동 컨트롤러의 직접적인 `Debug.LogError()` 호출을 프로젝트 공통 로그 체계인 `ProjectLog.Error()`로 변경했다.
- 기존 로그 분류와 오류 코드 규칙을 따르도록 정리했다.

#### 7. EditMode 자동 테스트 추가

`PlayerGroundMovementSolverTests`를 추가해 다음 항목을 검증했다.

- 전진 입력 시 기본 지상 가속도 사용
- 입력 해제 시 지상 감속도 사용
- 반대 입력 시 가속도와 감속도의 합산값 사용
- 연속된 반대 입력 계산에서 새 방향으로 속도 전환
- 90도 측면 입력을 반대 방향으로 오판하지 않음

### 기본 이동 수치

| 항목 | 값 |
|---|---:|
| 걷기 속도 | 6 m/s |
| 걷기 가속도 | 24 m/s² |
| 감속도 | 30 m/s² |
| 걷기 방향 전환 가속도 | 54 m/s² |
| 달리기 속도 | 8 m/s |
| 달리기 가속도 | 30 m/s² |
| 달리기 방향 전환 가속도 | 60 m/s² |
| 공중 가속도 | 12 m/s² |

### 테스트 결과

- 일반 이동 시 부드러운 가속 확인
- 입력 해제 시 자연스러운 감속과 정지 확인
- `W → S`, `S → W`, `A → D`, `D → A` 빠른 방향 전환 확인
- 측면과 대각선 입력 시 잘못된 반대 방향 판정 없음
- 대각선 이동 속도 정규화 유지
- 달리기 중 빠른 방향 전환과 스태미나 동작 확인
- 점프, 앉기, 외부 힘, 체크포인트와 부활 기능 회귀 테스트 완료
- `PlayerGroundMovementSolverTests` 5개 통과
- 기존 EditMode 테스트 통과
- 컴파일 오류와 Missing Script 없음
- Windows 개발 빌드 실행 확인

테스트 중 출력되는 다음 로그는 `ProjectLog.Error()` 동작을 검사하기 위한 의도된 예상 오류이며 테스트 실패가 아니다.

```text
[ProjectJ][Test][TEST_EXPECTED_ERROR] Expected test error.
```

### 완료 결과

플레이어가 정지 상태에서 자연스럽게 출발하고, 입력을 놓았을 때 짧게 감속하도록 이동감을 개선했다. 반대 방향 입력에는 더 높은 전환 가속도가 적용되어 기존보다 빠르게 정지하고 새 방향으로 움직일 수 있다. 기존 공중 이동과 점프·달리기·앉기·외부 힘 기능은 그대로 유지했다.
