# Project J - 124일차 개발일지

## 작업 제목
124일차 : 되감기 시계 서버 권한 5초 위치 기록 및 0.8초 역재생 구현

## 작업 목표
- 되감기 시계 아이템을 네트워크 아이템 목록에 등록한다.
- 서버 권한으로 플레이어의 최근 5초 위치를 기록한다.
- 아이템 사용 시 기록된 이동 경로를 0.8초 동안 역순으로 재생한다.
- 되감기 중 현재 시점의 장애물과 충돌하지 않도록 처리한다.
- 되감기 중 일반 이동, Push, 외력, 상태 방해가 경로 복원을 깨지 않도록 차단한다.
- 부활이나 경기 상태 변경 시 이전 위치 기록이 남지 않도록 정리한다.

## 구현 내용

### 1. 되감기 시계 네트워크 아이템 등록
- `ProjectJNetworkItemId.RewindClock = 23` 추가
- Item Key: `rewind_clock`
- 표시 이름: `되감기 시계`
- 기존 아이템 카탈로그의 ID 변환, Key 반환, 표시 이름 반환 분기에 연결

### 2. 서버 권한 위치 히스토리 기록
- State Authority가 플레이어 위치를 Tick 단위로 기록
- 기본 되감기 기록 길이: 5초
- 보간을 위한 추가 보관 시간: 0.5초
- Vector3 좌표가 NaN 또는 Infinity인 경우 기록에서 제외
- 5초 분량의 유효 기록이 쌓이지 않은 상태에서는 아이템 사용 실패
- 사용 실패 시 아이템을 소비하지 않음

### 3. 0.8초 경로 역재생
- 사용 시점에서 정확히 5초 전 위치를 목표점으로 계산
- 최근 5초 이동 기록을 0.8초 동안 역순으로 재생
- 기록 샘플 사이 위치는 보간하여 이동
- 역재생 종료 시 최종 위치를 5초 전 목표 위치로 보정
- 되감기 종료 후 기존 히스토리를 초기화하여 즉시 연속 사용을 방지

### 4. 안전 위치 검증
- 목표 위치가 유효한 Vector3인지 확인
- 현재 체크포인트의 낙하 한계보다 아래인 위치는 되감기 대상으로 허용하지 않음
- 잘못된 목표 위치에서는 사용 실패

### 5. 되감기 중 이동 및 외력 차단
- 되감기 활성 중 일반 이동 로직 차단
- 되감기 시작 시 기존 외부 속도 제거
- 되감기 진행 중 외부 속도를 계속 0으로 유지
- Push 입력 차단
- 되감기 중 들어오는 외부 힘을 차단하도록 기존 외력 보호 구조에 연결

### 6. 상태 효과 정리 및 충돌 방지
되감기 시작 시 이동 경로를 방해할 수 있는 일부 상태를 정리한다.

- 물총 Hold 종료
- 폭죽 준비 취소
- 낚시대 연결 해제
- 제트팩 종료
- 거대 풍선 종료
- 눈덩이 감속 제거
- 먹물 상태 제거
- 비눗방울 상태 제거
- 카트 탑승 중 사용 차단
- 갈고리 이동 중 사용 차단

되감기 중에는 플레이어 CapsuleCollider를 일시적으로 비활성화하여 현재 시점의 장애물을 통과할 수 있도록 처리하고, 종료 후 원래 Collider 활성 상태로 복원한다.

### 7. 다른 아이템과의 상호작용
- 되감기 중 자신의 Push 사용 차단
- 먹물 문어가 되감기 중인 플레이어에게 새 상태를 적용하지 않도록 차단
- 비눗방울이 되감기 중인 플레이어에게 새 상태를 적용하지 않도록 차단
- 기존 Jelly Shield, Respawn Protection 등 기존 보호 구조와 충돌하지 않도록 별도 Rewind 상태를 사용

### 8. 부활 및 경기 상태 처리
- 부활 횟수 변경을 감지하면 이전 위치 히스토리 초기화
- `ClearAuthority()` 시 되감기 상태와 기록 제거
- 부활 처리 시 이전 생명의 되감기 기록 제거
- Gameplay Lock 상태에서는 기록과 활성 되감기 상태를 정리
