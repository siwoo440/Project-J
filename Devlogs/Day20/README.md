# Project J 20일차 개발 일지

---

## 개발 목표

플레이어의 앉기 자세를 독립된 상태로 관리하고, 충돌체 전환·앉기 이동·점프 제한·천장 차단·밀치기 중 자세 처리를 하나의 흐름으로 통합했다.

---

## 구현 내용

### 1. 앉기 자세 상태 분리

- `PlayerCrouchStateController` 신규 작성
- 서기, 앉기 전환, 앉기, 서기 차단, 서기 전환 상태 구분
- 현재 높이와 목표 충돌체 높이 관리
- 부활 시 서기 상태로 초기화

### 2. 충돌체 높이 전환

- 서기 높이 `2.0`과 앉기 높이 `1.2` 사이를 부드럽게 전환
- 충돌체 높이에 맞춰 중심 위치를 조절해 발 위치 고정
- 천장 공간이 부족하면 앉은 높이 유지
- 공간 확보 후 자동으로 서기 자세 전환

### 3. 앉기 이동과 달리기 연동

- 앉기 상태에서 이동 속도 `3.5m/s` 적용
- 자세 전환 중에도 앉기 이동 속도 유지
- 달리기 중 앉기 입력 시 달리기 즉시 취소
- 대각선 이동 속도 제한 유지

### 4. 앉은 상태 점프 제한

- 앉기 전환 중 점프 차단
- 완전히 앉은 상태에서 점프 차단
- 천장으로 서기가 막힌 상태에서 점프 차단
- 완전히 서기 전까지 점프 입력 제한
- 앉은 상태에서 발생한 점프 입력을 버퍼에 저장하지 않도록 처리

### 5. 밀치기 중 자세 유지

- `PlayerExternalForceController`에 외부 힘 적용 상태 추가
- 밀치기를 받아도 현재 앉기 입력과 충돌체 높이 유지
- 외부 힘 종료 후 자세가 임의로 초기화되지 않도록 처리
- 천장 아래에서 밀치기를 받아도 서기 차단 상태 유지

### 6. 이동 컨트롤러 통합

- `PlayerMovementController`에 자세 제어기 연결
- 자세 상태에 따른 충돌체 높이와 중심 위치 적용
- 점프 가능 여부를 자세 상태와 연동
- 부활 시 충돌체, 자세, 점프 버퍼, 외부 힘 상태 초기화
