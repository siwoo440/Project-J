# 프로젝트 J 개발일지

---

## 42일차 : 28종 아이템 데이터 및 P0 아이템 효과 구현

---

### 개발 목표

41일차에 구축한 아이템 상자와 설치 위치 검사 시스템을 확장하여 28종 아이템 데이터를 등록하고, 우선순위가 높은 P0 아이템 10종을 실제로 사용할 수 있도록 구현한다.

---

### 주요 개발 내용

---

#### 1. 28종 아이템 데이터 등록

- `ITM-001`부터 `ITM-028`까지 아이템 데이터 생성
- 아이템별 이름, 설명, 구현 우선순위, 사용 방식, 효과 종류, 생성 가중치와 주요 수치 등록
- 구현 우선순위를 `P0`, `P1`, `P2`로 구분
- 사용 방식을 즉시형, 지속형, 투사체형, 설치형으로 구분
- `ITM-014`의 명칭을 `복어 갑옷`으로 확정
- P1·P2 아이템은 후속 일차 구현을 위한 데이터와 실행 종류만 연결

---

#### 2. P0 아이템 10종 효과 구현

| ID | 아이템 | 구현 효과 |
|---|---|---|
| ITM-001 | 스프링 신발 | 8초 동안 공중 추가 점프 1회 제공 |
| ITM-002 | 젤리 보호막 | 4초 동안 외부 밀치기와 방해 힘 무효화 |
| ITM-003 | 바나나 쿠션 | 설치 후 밟은 대상을 설치 방향으로 밀어냄 |
| ITM-004 | 풍선 나팔 | 전방 7m·60도 범위의 대상을 밀어냄 |
| ITM-005 | 물총 | 2.5초 동안 직선 물줄기로 대상을 연속 밀어냄 |
| ITM-006 | 폭죽 | 0.9초 준비 후 전방 범위를 강하게 밀어냄 |
| ITM-007 | 깃털 신발 | 7초 동안 이동 속도 25% 증가 |
| ITM-008 | 눈덩이 | 적중 대상의 이동 속도를 3초 동안 25% 감소 |
| ITM-009 | 지뢰 | 접근한 대상을 위쪽과 바깥쪽으로 밀어낸 뒤 제거 |
| ITM-010 | 풀 공 | 약한 밀치기 투사체를 한 슬롯에 최대 5개까지 중첩 |

---

#### 3. 아이템 선택과 사용 입력 구현

- `Q` 입력으로 첫 번째 인벤토리 슬롯 선택
- `E` 입력으로 두 번째 인벤토리 슬롯 선택
- 마우스 우클릭으로 선택한 아이템 사용
- 스프링 신발 활성 중 `Space` 입력으로 공중 추가 점프 사용
- 선택 슬롯과 현재 보유 수량을 Canvas HUD에 표시

---

#### 4. 공통 아이템 실행 구조 구현

- 아이템 사용 결과를 처리하는 공통 관리자 추가
- 지속 효과의 시작, 종료와 중복 적용 처리 구조 구성
- 투사체의 이동, 충돌, 거리 제한과 밀치기 처리 구성
- 설치형 아이템을 41일차 공통 설치 위치 검사기와 연결
- 사용 성공, 설치 실패, 미구현 아이템 안내를 HUD에 표시
- P1·P2 아이템 사용 시 소비하지 않고 후속 구현 예정 안내 표시

---

#### 5. 인벤토리와 상자 시스템 확장

- 기존 2슬롯 인벤토리에 선택 슬롯 상태 추가
- 아이템별 최대 중첩 수량 처리 추가
- 풀 공을 한 슬롯에 최대 5개까지 보관하도록 구현
- 아이템 사용 시 현재 슬롯 수량을 차감하고 소진된 슬롯 정리
- 28종 아이템의 생성 가중치를 상자 후보 선택에 반영

---

#### 6. UI 개선

- 선택된 슬롯의 배경과 슬롯 문구 강조
- 슬롯에 `Q`, `E` 조작 키 표시
- 중첩 아이템의 수량 표시
- 아이템 사용 성공과 실패 사유를 표시하는 `ItemUseStatusText` 추가

---

#### 7. 자동 설정 도구와 테스트 추가

- Game Scene에 42일차 아이템 시스템을 연결하는 Editor 자동 설정 도구 추가
- 생성 가중치 구간과 28종 효과 열거형을 확인하는 EditMode 테스트 추가
- 풀 공 5개 중첩과 슬롯 선택 상태를 확인하는 EditMode 테스트 추가

---

### 조작 방법

| 입력 | 기능 |
|---|---|
| Q | 첫 번째 아이템 슬롯 선택 |
| E | 두 번째 아이템 슬롯 선택 |
| 마우스 우클릭 | 선택 아이템 사용 |
| Space | 스프링 신발 활성 중 공중 추가 점프 |

---

### 구현 결과

- 28종 아이템을 공통 데이터 형식으로 관리할 수 있게 됐다.
- P0 아이템 10종을 획득하고 선택하여 사용할 수 있는 흐름이 완성됐다.
- 지속형, 투사체형, 설치형 효과를 후속 아이템 구현에서도 재사용할 수 있게 됐다.
- 2슬롯 인벤토리에서 선택 상태와 중첩 수량을 확인할 수 있게 됐다.
- P1·P2 아이템을 다음 일차에 단계적으로 구현할 기반이 마련됐다.

---

### 확인 필요 항목

다음 항목은 Unity Editor에서 직접 실행하여 확인해야 한다.

- 전체 Assembly 컴파일 오류 여부
- P0 아이템 10종의 실제 물리 효과와 체감 수치
- 상자에서 28종 생성 가중치가 정상 적용되는지 여부
- 바나나 쿠션과 지뢰의 설치 위치 및 충돌 판정
- 눈덩이 감속의 실제 플레이어 대상 적용 여부
- 부활과 경기 종료 시 지속 효과 정리 여부
- EditMode Test Runner 전체 통과 여부
