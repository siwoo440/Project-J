# 프로젝트 J 29일차 개발 일지

## 개발 목표

밀치기 규칙, 실제 높이 기반 순위, 10분 경기 종료 흐름을 하나의 경기 시스템으로 통합한다.

## 주요 개발 내용

### 1. 밀치기 규칙 완성

- 기본 밀치기 힘과 재사용 대기시간 적용
- 피격 후 연속 밀치기 면역 적용
- 같은 프레임에 들어온 여러 밀치기 힘을 벡터로 합산
- 반대 방향 밀치기 힘 상쇄
- 합산된 밀치기 속도를 최대값 이내로 제한
- 면역 종료 후 남은 힘과 새 밀치기 힘 누적
- 부활 보호 중 플레이어 몸체 충돌과 밀치기 차단

### 2. 실제 높이 기반 실시간 순위

- 시작점 기준 플레이어와 더미의 실제 현재 높이 계산
- 현재 높이가 높은 참가자부터 실시간 순위 정렬
- 높이 차이가 `0.05m` 이내인 참가자를 공동 순위로 처리
- 공동 순위 다음 번호를 참가자 수만큼 건너뛰는 `1위·1위·3위` 규칙 적용
- 공동 순위 내부 표시 순서를 높이 도달 시간과 참가자 등록 순서로 고정
- HUD에 참가자 이름, 현재 높이, 순위 표시

### 3. 경기 타이머와 종료 판정

- 기본 경기 시간을 `600초`로 설정
- 정상 지점 도달 시 경기 즉시 종료
- 제한 시간 만료 시 현재 높이를 기준으로 최종 순위 확정
- 단독 1위를 승리, 공동 1위를 공동 승리, 2위 이하를 패배로 판정
- 경기 종료 후 플레이어 입력, 밀치기, 부활, 더미 이동 차단
- 경기 결과 오버레이에 종료 원인, 최종 순위, 높이, 정상 도달 여부 표시

## 적용 규칙

| 항목 | 값 또는 규칙 |
|---|---|
| 기본 밀치기 힘 | `6` |
| 밀치기 재사용 대기시간 | `1.2초` |
| 연속 피격 면역 | `0.8초` |
| 최대 합산 밀치기 속도 | `10` |
| 공동 순위 높이 허용 오차 | `0.05m` |
| 경기 제한 시간 | `600초` |
| 순위 기준 | 종료 순간의 실제 현재 높이 |
| 정상 도달 | 즉시 경기 종료 및 우선 순위 처리 |

## 완료 결과

29~31일차로 나누어 계획했던 밀치기, 순위, 경기 종료 기능을 29일차에 통합했다. 플레이어의 현재 높이와 정상 도달 여부가 최종 결과에 연결되며, 경기 시작부터 종료 화면까지 한 흐름으로 동작하도록 구성했다.

Unity 컴파일, EditMode 테스트, 실제 물리 충돌, HUD와 결과 화면은 로컬 Unity 에디터에서 최종 확인이 필요하다.
