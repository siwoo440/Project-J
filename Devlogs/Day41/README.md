# 프로젝트 J 41일차 개발일지

---

## 개발 주제

**아이템 상자 생성 규칙 및 설치 위치 공통 검사 구현**

절차적으로 생성되는 경기 맵에 아이템 상자를 배치할 수 있도록 생성 위치, 확률, 간격, 최대 개수와 재생성 규칙을 구현했다. 기존 2슬롯 인벤토리와 Canvas HUD를 상자 획득 흐름에 연결하고, 이후 설치형 아이템에서도 재사용할 수 있는 공통 위치 검사 구조를 추가했다.

---

## 이번 일차 목표

- 절차 생성 모듈을 기준으로 상자 생성 후보 위치 계산
- 시작 모듈과 마지막 모듈 생성 제외
- 모듈별 확률과 최대 생성 개수 적용
- 인접 모듈의 상자 중복 생성 방지
- 획득 후 제한적인 상자 재생성 처리
- 맵 재생성 시 이전 상자 제거 및 위치 재계산
- 지면, 경사, 장애물과 허용 영역 공통 검사
- 상자 획득 결과를 기존 2슬롯 아이템 HUD에 반영
- 생성 규칙과 위치 계산 규칙의 EditMode 테스트 추가

---

## 주요 구현 내용

### 1. 절차 맵 기반 아이템 상자 생성

`ItemChestSpawner`를 추가해 `ProceduralMapGenerator`가 만든 모듈 정보를 감시하고, 맵 생성이 완료되면 상자 후보를 계산하도록 구성했다.

적용된 기본 규칙은 다음과 같다.

| 항목 | 설정값 |
|---|---:|
| 모듈별 생성 확률 | 35% |
| 최대 상자 지점 | 4개 |
| 생성 제외 모듈 | 시작·마지막 모듈 |
| 상자 사이 최소 모듈 간격 | 2 |
| 모듈별 위치 검사 횟수 | 8회 |
| 모듈 가장자리 여백 | 0.9m |
| 상자 검사 절반 크기 | 0.6m |

확률 검사와 설치 위치 검사를 모두 통과한 후보만 실제 상자 지점으로 사용한다. 최대 개수는 상한값이므로 매 경기 정확히 4개가 생성되는 구조는 아니다.

### 2. 상자 생성 규칙 분리

`ItemChestSpawnRules`에 확률 판정, 생성 가능한 모듈 인덱스, 모듈 간 최소 간격과 재생성 가능 횟수 계산을 분리했다. MonoBehaviour와 독립된 순수 규칙으로 구성해 Unity Test Runner에서 직접 검증할 수 있도록 했다.

### 3. 상자 획득과 제한적 재생성

`ItemChestPickup`에 획득 성공 이벤트와 런타임 설정 기능을 추가하고, `ItemChestSpawnPoint`가 각 생성 지점의 상태를 관리하도록 구성했다.

- 상자 획득 후 20초 대기
- 같은 지점에서 최대 1회 추가 생성
- 경기 종료 후 재생성 중단
- 인벤토리가 가득 찬 경우 상자를 제거하지 않고 유지
- 맵 구성이 바뀌면 이전 지점과 상자를 정리한 뒤 다시 배치

### 4. 보유 아이템 HUD 연결 유지

상자 획득 시 `PlayerItemInventory.TryAddItem()`을 호출하며, 기존 `InventoryChanged` 이벤트를 통해 Canvas의 2슬롯 표시가 갱신되는 구조를 유지했다.

```text
상자 접촉
→ 아이템 획득 시도
→ PlayerItemInventory 갱신
→ InventoryChanged 이벤트
→ MinimalPlayerHud 슬롯 갱신
```

두 슬롯이 모두 사용 중이면 획득이 실패하고 상자는 현재 위치에 남는다.

### 5. 설치 위치 공통 검사기 구현

`ItemPlacementValidator`를 추가해 상자와 이후 설치형 아이템이 함께 사용할 수 있는 위치 검사를 구성했다.

검사 순서는 다음과 같다.

1. 후보 위치가 허용된 모듈 영역 안인지 확인
2. 아래 방향 Raycast로 설치 지면 확인
3. 지면 법선으로 경사 각도 확인
4. OverlapBox로 설치 공간의 장애물 확인
5. 모든 조건을 통과하면 지면 높이가 보정된 최종 위치 반환

| 실패 결과 | 의미 |
|---|---|
| `NoGround` | 아래 방향에서 지면을 찾지 못함 |
| `SlopeTooSteep` | 지면 경사가 허용 각도 35도를 초과함 |
| `Blocked` | 설치 공간이 다른 Collider와 겹침 |
| `OutsideAllowedArea` | 모듈 가장자리 여백을 포함한 허용 영역 밖임 |

최근 검사 결과는 Scene 뷰의 Gizmo로 확인할 수 있도록 구성했다.

### 6. Game Scene 자동 설정

`Day41ItemChestPlacementSetupTool`을 추가해 Game Scene에 필요한 오브젝트와 참조를 자동으로 구성하도록 했다.

```text
Day41_ItemChestSystem
├── ItemChestSpawner
└── ItemPlacementValidator
```

기존 39일차 고정 시험 상자 오브젝트는 제거하고, 실제 절차 맵 기반 생성 시스템으로 교체했다. Item Pool에는 기존 아이템 데이터 3종이 연결되어 있다.

### 7. 규칙 테스트 추가

다음 EditMode 테스트 코드를 추가했다.

- 35% 확률 경계 판정
- 시작·마지막 모듈 제외
- 인접 모듈 간격 제한
- 지점별 재생성 횟수 제한
- 평지 설치 허용
- 급경사 설치 차단
- 모듈 가장자리 여백 적용

테스트 코드가 저장소에 포함된 사실은 확인했으며, Unity Test Runner의 실제 통과 결과는 Unity Editor에서 별도 확인이 필요하다.

### 8. UI 텍스트 표시 보정

Game Scene의 여러 TextMeshPro 텍스트 Overflow 설정을 변경하고 `NotoSansKR-Regular SDF` 에셋을 갱신해 한글 UI 표시 상태를 함께 보정했다.
