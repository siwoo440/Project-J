# 프로젝트 J 22일차 개발일지

## 개발 목표

플레이어의 공중 이동과 지형 대응 기능을 확장하고, 다음 일차의 끝자락 올라오기 기능에서 사용할 탐지 구조를 구축했다.

## 구현 내용

### 1. 공중 제어 개선

- 점프 직전의 수평 관성 보존
- 공중 입력이 있을 때만 제한된 가속도로 방향 전환
- 달리기 점프 중 입력을 놓아도 진입 속도 유지
- 공중에서 추가 점프가 발생하지 않도록 기존 점프 제한 유지

### 2. 경사면 이동

- 지면 법선과 경사 각도 탐지
- `CharacterController`의 `Slope Limit` 이내 경사만 이동 가능하도록 판정
- 수평 속도를 경사면에 투영해 오르막과 내리막 이동 안정화
- 이동 가능한 경사에서 속력의 크기가 불필요하게 변하지 않도록 보정

### 3. 계단 이동

- 접지 상태에서 기존 `Step Offset 0.3m` 사용
- 점프와 낙하 중 `Step Offset`을 `0`으로 변경
- 착지 후 원래 계단 오프셋 자동 복원
- 공중에서 계단이나 단차를 비정상적으로 타고 오르는 현상 방지

### 4. 공중 모서리 보정

- 공중에서 벽 가장자리를 감지하는 탐지 구조 추가
- 모서리에 걸렸을 때 벽을 따라 이동하도록 방향 보정
- 접지 상태에서는 기존 `CharacterController` 충돌 처리 유지

### 5. 끝자락 감지

- 몸통 높이에서 전방 벽 탐지
- 머리 높이의 이동 공간 확인
- 벽 너머의 윗면 위치와 경사 확인
- 올라올 수 있는 끝자락 위치와 벽 법선 저장
- Scene 뷰에서 탐지 결과를 확인할 수 있는 기즈모 추가

이번 일차에서는 끝자락을 감지하는 구조까지만 구현했으며, 실제 올라오기 동작은 다음 일차에 연결한다.

## 변경 파일

| 구분 | 파일 | 역할 |
|---|---|---|
| 수정 | `PlayerMovementController.cs` | 공중 제어와 지형 탐지 통합 |
| 생성 | `PlayerTraversalMath.cs` | 공중·경사·모서리 이동 계산 |
| 생성 | `PlayerTraversalProbe.cs` | 경사·벽·끝자락 물리 탐지 |
| 생성 | `PlayerTraversalMathTests.cs` | 이동 계산 EditMode 테스트 |

## 주요 설정값

| 항목 | 값 |
|---|---:|
| 공중 제어 비율 | `0.65` |
| 공중 방향 전환 가속도 | `12` |
| 경사 제한 | `45도` |
| 계단 오프셋 | `0.3m` |
| 지면 탐지 거리 | `0.35m` |
| 모서리 탐지 거리 | `0.2m` |
| 모서리 보정 강도 | `0.75` |
| 끝자락 전방 탐지 거리 | `0.2m` |
| 끝자락 상단 탐색 높이 | `1.5m` |

## 자동 테스트

`PlayerTraversalMathTests`에 다음 8개 테스트를 추가했다.

1. 공중 무입력 상태의 수평 관성 보존
2. 정지 상태 공중 입력의 제어 비율 적용
3. 공중 방향 전환 가속도 제한
4. 제한 각도 이내 경사 판정
5. 제한 각도 초과 경사 판정
6. 경사 정렬 후 이동 속력 유지
7. 가파른 경사에서 속도 미변경
8. 벽을 따르는 모서리 이동 방향 계산

기존 점프, 달리기, 앉기, 지상 이동 테스트와 함께 전체 실패가 없는지 확인했다.

## 수동 확인 내용

- 이동 중 점프 후 입력 해제 시 수평 관성 유지
- 공중 입력 시 방향이 즉시 꺾이지 않고 점진적으로 변경
- 달리기 점프 속도 유지
- `15도`, `30도`, `44도` 경사 이동
- `50도` 경사 일반 이동 차단
- `0.3m` 이하 계단 이동
- 공중 상태 계단 오프셋 비활성화
- 벽 모서리 충돌 시 이동 정지 완화
- 끝자락 위치와 법선 기즈모 표시
- 부활 시 이동·점프·지형 탐지 상태 초기화
- 기존 이동, 달리기, 앉기, 점프, 밀치기 기능 유지

## 완료 결과

- 공중 관성과 제한된 방향 전환 구현
- 경사면 이동 안정화
- 접지·공중 상태별 계단 오프셋 처리
- 공중 모서리 이동 보정
- 끝자락 벽과 윗면 감지
- 끝자락 위치와 법선 공개
- 지형 탐지 기즈모 추가
- EditMode 테스트 8개 추가
- 기존 이동 기능 회귀 확인
