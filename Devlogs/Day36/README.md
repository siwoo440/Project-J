# 프로젝트 J 36일차 개발일지

## 개발 목표

35일차에 구현한 XYZ 수직 선형 생성 기능을 기존 분기·합류 구조로 확장한다. 좌우 분기가 서로 다른 경로를 거치더라도 같은 높이에서 합류하도록 만들고, 생성에 실패한 조합은 안전하게 취소한 뒤 다시 시도할 수 있도록 구성한다.

## 작업 내용

### 수직 분기·합류 생성 구현

- 수직 생성과 분기 생성을 동시에 사용할 수 있도록 생성 모드 확장
- 시작 모듈, 분기 모듈, 좌우 경로, 합류 모듈, 공통 후속 경로로 이어지는 8개 모듈 구조 구현
- 좌우 분기의 누적 높이와 상승 모듈 수를 개별 관리
- 양쪽 경로가 같은 높이에 도달할 수 있는 후보 조합만 선택
- 합류 지점에서 좌우 연결부와 합류 모듈의 XYZ 위치 검사
- 각 분기에 최소 1개 이상의 상승 모듈이 포함되도록 제한
- 분기 구간 이후에도 최종 목표 높이를 달성할 수 있는지 사전 계산

### 실패 조합 롤백 및 재시도

합류할 수 없는 후보 조합이 선택되면 다음 상태를 분기 직후 시점으로 복원하도록 처리했다.

- 생성된 분기 모듈
- 그래프 노드와 간선
- 연결 지점 사용 상태
- 좌우 분기 누적 높이
- 분기별 상승 모듈 수
- 연속 평지 모듈 수

복원 후에는 새로운 후보 조합을 선택해 다시 생성하며, 실패한 조합의 상태가 다음 시도에 남지 않도록 구성했다.

### 기존 생성 모드 호환성 유지

- 기존 수평 분기 생성 유지
- 35일차 수직 선형 생성 유지
- 수직 생성과 분기 생성이 모두 활성화된 경우에만 신규 수직 분기 생성 사용
- 기존 공개 API와 네임스페이스 유지

### 설정 도구 추가

Unity 상단 메뉴에 다음 설정 항목을 추가했다.

```text
Project J
└── Day 36
    └── Configure Vertical Branch Generation
```

주요 적용값은 다음과 같다.

| 설정 | 값 |
|---|---:|
| 고정 시드 | `36001` |
| 생성 모듈 수 | `8` |
| 분기 경로당 모듈 수 | `2` |
| 목표 높이 | `8~16m` |
| 전체 최소 상승 모듈 수 | `3` |
| 분기별 최소 상승 모듈 수 | `1` |
| 최대 연속 평지 모듈 수 | `2` |
| 합류 높이 허용 오차 | `0.02m` |
| 최대 조합 재시도 횟수 | `64` |

## 생성 구조

```text
시작 모듈
    ↓
분기 모듈
  ↙     ↘
왼쪽 1  오른쪽 1
  ↓       ↓
왼쪽 2  오른쪽 2
  ↘     ↙
합류 모듈
    ↓
공통 후속 모듈
```

정상 생성 시 그래프 노드 8개와 간선 8개가 만들어진다.

## 작업 결과

수직 선형 생성 기능을 좌우 분기 경로까지 확장했다. 생성기는 양쪽 경로의 높이를 따로 계산하고, 같은 높이에 도달할 수 있는 조합만 배치한다. 합류가 불가능한 경우에는 생성 상태를 복원하고 다시 시도하므로 실패한 배치가 이후 생성에 영향을 주지 않는다.
