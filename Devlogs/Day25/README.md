# Project J 개발 일지

---

## 25일차 : 월드 높이·최고 기록 및 5개 수직 구간 진행 시스템

### 개발 목표

플레이어의 월드 높이를 실시간으로 계산하고 현재 높이와 최고 높이를 분리하여 관리한다. 전체 1000m 코스를 5개 수직 구간으로 나누고, 현재 구간과 진행률을 HUD에 표시한다.

### 구현 내용

- `HeightOrigin`과 플레이어의 Y 좌표 차이를 미터 단위 높이로 계산
- 현재 높이를 플레이어 위치에 따라 실시간 갱신
- 추락하거나 부활해도 최고 높이 기록 유지
- 전체 코스 높이와 구간 수를 Inspector에서 설정 가능하도록 구성
- 전체 1000m 코스를 200m 단위의 5개 구간으로 판정
- 전체 코스 진행률과 현재 구간 내부 진행률 계산
- 코스 정상 도달 여부 제공
- 높이 계산을 부활 시스템에서 별도 진행 컴포넌트로 분리
- 기존 부활 및 순위 시스템의 `CurrentHeight`, `HighestHeight` 호환 유지
- HUD에 현재 높이, 최고 높이, 현재 구간과 전체 진행률 표시

### 수직 구간 기준

| 구간 | 높이 범위 |
|---:|---:|
| 1구간 | 0m 이상 ~ 200m 미만 |
| 2구간 | 200m 이상 ~ 400m 미만 |
| 3구간 | 400m 이상 ~ 600m 미만 |
| 4구간 | 600m 이상 ~ 800m 미만 |
| 5구간 | 800m 이상 ~ 1000m 이상 |

### 수정 및 생성 파일

| 구분 | 파일 | 역할 |
|---|---|---|
| 생성 | `WorldHeightProgressMath.cs` | 높이·구간·진행률 계산 |
| 생성 | `PlayerHeightProgressController.cs` | 현재·최고 높이와 진행 상태 관리 |
| 수정 | `PlayerRespawnController.cs` | 기존 높이 계산 제거 및 새 진행 컴포넌트 연결 |
| 수정 | `MinimalPlayerHud.cs` | 현재·최고 높이, 구간과 전체 진행률 표시 |
| 생성 | `WorldHeightProgressMathTests.cs` | 높이 계산 EditMode 테스트 10개 |

### 주요 설정값

`Player`의 `PlayerHeightProgressController`에 다음 값을 적용했다.

| 항목 | 값 |
|---|---:|
| Height Origin | 기존 `HeightOrigin` 오브젝트 |
| Meters Per Unity Unit | `1` |
| Total Course Height | `1000` |
| Section Count | `5` |

`PlayerRespawnController`의 추락 및 부활 관련 값은 기존 설정을 유지했다.

| 항목 | 값 |
|---|---:|
| Fall Limit Y | 기존값 유지 |
| Respawn Delay | `0.75` |
| Respawn Vertical Offset | `0.05` |

### 높이 처리 흐름

1. 플레이어의 월드 Y 좌표를 확인한다.
2. `HeightOrigin`의 Y 좌표를 차감한다.
3. `Meters Per Unity Unit`을 적용하여 미터 높이로 변환한다.
4. 음수 높이를 0m로 제한하고 현재 높이를 갱신한다.
5. 기존 최고 높이와 비교하여 더 높은 값을 기록한다.
6. 현재 높이를 기준으로 5개 수직 구간 중 하나를 판정한다.
7. 전체 코스 진행률과 현재 구간 내부 진행률을 계산한다.
8. 계산 결과를 HUD와 기존 순위 시스템에 제공한다.

### HUD 표시

HUD에서 다음 정보를 확인할 수 있도록 수정했다.

```text
현재 350.0 m | 최고 420.0 m
구간 2/5 | 전체 35%
```

- 현재 높이는 플레이어의 실제 위치에 따라 증감
- 최고 높이는 추락 및 부활 이후에도 유지
- 전체 코스 진행 막대는 0~100% 범위로 표시
- 기존 체크포인트, 남은 시간, 순위와 스태미나 표시 유지

### 자동 테스트

`WorldHeightProgressMathTests`에 다음 10개 테스트를 추가했다.

1. 기준점과 플레이어 위치 차이로 높이 계산
2. 0m 미만 높이 차단
3. 유니티 단위와 미터 변환 적용
4. 추락 후 최고 높이 감소 방지
5. 시작 높이의 1구간 판정
6. 구간 경계에서 다음 구간 판정
7. 정상 높이의 마지막 구간 유지
8. 정상 초과 진행률을 100%로 제한
9. 현재 구간 범위에 따른 구간 진행률 계산
10. 잘못된 구간 수 입력 시 1개 구간으로 보정
