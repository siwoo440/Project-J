## 개발 목표

42일차와 43일차에 구축한 아이템 데이터 및 P0·P1 효과 구조를 유지하면서, 구현 난도가 높은 P2 아이템 7종의 실제 사용 효과를 완성한다.

- 되감기 시계의 안전 위치 기록과 충돌 없는 역재생
- 유도탄과 드론의 목표 탐색·추적·재선정
- 소형화 물약의 외형 및 충돌체 축소
- 투명 망토의 외형 숨김과 추적 대상 제외
- 저격 물총의 조준·배율·발사·소비 처리
- 카트의 Waypoint 기반 자동 주행
- 부활 및 경기 종료 시 P2 효과 정리

## 주요 개발 내용

### 1. P2 아이템 데이터 7종 갱신

P2 아이템의 설명과 실제 효과 수치를 데이터에 반영했다.

| ID | 아이템 | 적용 내용 |
|---|---|---|
| ITM-022 | 되감기 시계 | 최근 5초 안전 위치를 1.25초 동안 충돌 없이 역재생 |
| ITM-023 | 유도탄 | 가장 가까운 대상을 초당 16m로 추적하고 힘 12 적용, 재선정 1회 |
| ITM-024 | 소형화 물약 | 6초 동안 외형과 충돌체를 80% 크기로 축소 |
| ITM-025 | 드론 | 현재 1위 대상을 초당 12m로 추적하고 힘 10 적용, 재선정 1회 |
| ITM-026 | 투명 망토 | 5초 동안 외형을 숨기고 유도탄·드론 추적 대상에서 제외 |
| ITM-027 | 저격 물총 | 최대 50m 조준, 힘 14 적용, 1.5~4배 배율 지원 |
| ITM-028 | 카트 | 가까운 연결 경로를 초당 10m로 최대 8초 자동 주행 |

### 2. 되감기 시계 구현

- 플레이어의 최근 안전 위치를 일정 간격으로 기록
- 최근 5초의 기록을 1.25초 동안 역순으로 재생
- 되감는 동안 이동·달리기·앉기 입력 제한
- 되감기 중 CharacterController 충돌 비활성화
- 완료 또는 중단 시 충돌과 입력 상태 복원
- 부활 및 경기 종료 상황에서 되감기 상태 정리

### 3. 유도탄과 드론 추적 구현

- 유도탄은 가장 가까운 유효 대상을 선택
- 드론은 발 위치 높이를 소수점 둘째 자리까지 남기고 뒷자리를 버려 현재 1위 판정
- 같은 비교 높이에서는 더 가까운 대상을 우선 선택
- 대상이 무효화되면 최대 1회 재선정
- 투명 망토 사용자는 추적 대상에서 제외
- 충돌 시 설정된 힘을 대상에게 적용

### 4. 소형화 물약 구현

- 플레이어 외형을 80% 크기로 축소
- CharacterController의 반지름과 높이를 같은 비율로 조정
- 6초 후 원래 외형과 충돌체 크기로 복원
- 비정상적인 축소값이 적용되지 않도록 안전 범위 보정

### 5. 투명 망토 구현

- 지속 시간 동안 플레이어 외형 숨김
- 유도탄과 드론의 신규 목표 선정에서 제외
- 이미 추적 중인 대상이 투명 상태가 되면 목표 해제 또는 재선정
- 효과 종료 시 원래 외형 표시 상태 복원

### 6. 저격 물총 구현

- 우클릭 또는 게임패드 LT로 조준 시작
- 마우스 휠 또는 게임패드 LB·RB로 1.5~4배 배율 변경
- 좌클릭 또는 게임패드 RT로 발사
- Escape·우클릭·게임패드 B로 조준 취소
- 조준 취소 시 아이템 미소비
- 실제 발사 시점에만 슬롯의 저격 물총 소비
- 최대 50m 안의 첫 충돌 대상을 힘 14로 밀치도록 처리

### 7. 카트 자동 주행 구현

- `CartPath`를 이용한 Waypoint 기반 경로 구조 추가
- 가까운 카트 경로 탐색
- 경로 지점을 순서대로 따라 최대 8초 동안 자동 주행
- 자동 주행 중 일반 이동 입력 제한
- 테스트용 `Day44_CartRoute`와 Waypoint 5개를 Game Scene에 배치
- Scene 뷰에서 경로를 확인할 수 있는 Gizmo 연결

### 8. Player와 Game Scene 연결

Player에 다음 P2 전용 컴포넌트를 추가하고 기존 아이템 사용 구조와 연결했다.

- `PlayerP2ItemEffectController`
- `PlayerRewindRecorder`
- `PlayerSniperWaterGunController`

`PlayerItemUseController`에는 P2 효과 관리자와 저격 관리자를 연결했으며, `PlayerInputReader`에는 되감기와 카트용 이동 제한 상태를 추가했다.

### 9. 자동 설정 및 EditMode 테스트 추가

- P2 아이템 7종과 Player 참조를 자동 연결하는 44일차 설정 도구 추가
- 되감기 표본 선택 규칙 테스트
- P2 효과가 정확히 7종인지 확인하는 테스트
- 드론의 높이 절삭 및 동률 거리 우선 규칙 테스트
- 소형화 배율 안전 범위 테스트
- 저격 물총 배율 최소·최대값 테스트

현재 확정된 아이템 시스템 개발 일정은 45일차까지이며, 남은 일정은 1일이다.

| 43일차 | P1 아이템 11종 효과 구현 | 완료 |
| 44일차 | P2 아이템 7종 효과 구현 | 완료 |
| 45일차 | 28종 아이템 통합 테스트 및 밸런스 검증 | 남은 작업 |

### 45일차 개발 범위

- 28종 전체 아이템의 획득·선택·사용·소비 확인
- Q·E 두 슬롯 선택과 우클릭 사용 흐름 검증
- 슬롯 교체 및 최대 중첩 규칙 검증
- 공격·방어·이동·설치·화면 방해 효과의 상호작용 검사
- 같은 효과와 서로 다른 효과의 중복 사용 규칙 점검
- 보호막과 공격 아이템의 처리 우선순위 검사
- 설치형 아이템의 지면·경사·장애물 판정 검사
- 부활·추락·결승점 도달·경기 종료 시 상태 초기화 검사
- 아이템 상자 생성 가중치와 등급별 등장 확률 조정
- HUD 상태 안내와 사용 실패 사유 정리
- EditMode 및 PlayMode 테스트 보강
- 실제 플레이 결과에 따른 수치 조정과 아이템 데이터 동기화

45일차 이후 개발 일정은 현재 확인된 자료에 확정되어 있지 않다. 다음 기능 일정은 45일차 통합 검증 결과와 전체 프로젝트 로드맵을 기준으로 새로 정해야 한다.
