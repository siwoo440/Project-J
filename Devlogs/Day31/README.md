# 31일차 : 시드 기반 선형 맵 생성 및 자동 연결

---

## 오늘의 목표

30일차에 제작한 맵 모듈 규격과 이동 검증 데이터를 실제 절차적 맵 생성기에 연결하고, 동일한 시드에서 같은 구조가 생성되는 선형 맵 생성 기반을 구축했다.

---

## 구현 내용

1. 시드 기반 맵 생성 설정

* 고정 생성 시드 설정
* 실행마다 시드를 변경하는 무작위 생성 옵션
* 첫 번째 모듈의 시작 회전 설정
* 목표 모듈 개수 설정
* 모듈별 최대 배치 시도 횟수 설정
* 모듈 영역 겹침 허용 오차 설정
* 생성에 사용할 모듈 Prefab 목록 관리

2. 모듈 배치 공통 규칙

* 모듈별 허용 회전값 검사
* 0도·90도·180도·270도 회전 지원
* 연결 지점의 월드 방향 비교
* 출구와 입구가 서로 마주 보는지 검사
* 두 연결 지점의 위치가 일치하도록 모듈 위치 계산
* Bounds가 경계만 맞닿은 경우 배치 허용
* 실제 영역이 겹치는 모듈 배치 차단

3. 선형 맵 자동 생성

* 유효한 모듈 Prefab만 생성 후보로 수집
* 잘못된 모듈 데이터 자동 제외
* 첫 번째 모듈 무작위 선택 및 배치
* 이전 모듈의 출구를 기준으로 다음 모듈 연결
* Prefab과 허용 회전을 조합한 배치 후보 생성
* 시드 기반으로 배치 후보 순서 무작위화
* 호환되는 입구 자동 선택
* 기존 모듈과 겹치는 후보 제거
* 목표 개수까지 순차적으로 모듈 연결
* 생성 실패 시 현재까지 배치된 부분 맵 유지
* 생성 결과와 실제 사용 시드를 Console에 출력

4. 생성 결과 관리

* 게임 시작 시 자동으로 맵 생성
* 이전 생성 결과 제거 후 재생성
* 생성된 모듈을 `GeneratedMap` 아래에서 일괄 관리
* 생성된 모듈의 순서를 이름에 표시
* Inspector 메뉴를 통한 수동 생성 및 제거 지원
* 생성 성공 여부와 생성 모듈 개수 제공

5. Editor 자동 구성 도구

* 31일차 전용 Unity Editor 메뉴 추가
* 기본 생성 설정 에셋 자동 생성 및 갱신
* 30일차 기본 맵 모듈 3종 자동 연결
* Scene의 맵 생성기 오브젝트 자동 구성
* `GeneratedMap` 보관 루트 자동 구성
* 필요한 Prefab 누락 시 오류 메시지 출력
* 생성 설정과 Scene 변경 상태 자동 저장 처리

6. 기본 생성 데이터

다음 기본값을 적용했다.

| 항목       |     설정값 |
| -------- | ------: |
| 고정 시드    | `31001` |
| 무작위 시드   |    비활성화 |
| 시작 회전    |    `0도` |
| 목표 모듈 개수 |    `8개` |
| 최대 배치 시도 |   `32회` |
| 겹침 허용 오차 | `0.05m` |
| 생성 후보 모듈 |    `3종` |

생성 후보에는 다음 모듈을 등록했다.

* 기본 직선 통로
* 앉아서 통과하는 낮은 통로
* 점프로 통과하는 간격 모듈

## 자동 테스트 구성

`MapGenerationRulesTests`에 다음 8개 검증 항목을 추가했다.

* 전체 직각 회전 목록 검사
* 단일 직각 회전 선택 검사
* 북쪽과 남쪽의 반대 방향 판정
* 같은 방향의 연결 차단
* 연결 지점 위치 정렬 계산
* 경계만 맞닿은 Bounds 허용
* 실제로 교차하는 Bounds 차단
* 90도 회전 후 방향 검사

GitHub 저장소에서 테스트 코드 구성은 확인했지만, 실제 Unity Test Runner 실행 결과는 별도 확인이 필요하다.

## 완료 결과

30일차에 정의한 맵 모듈을 이용해 고정 시드 기반의 선형 맵을 자동 생성할 수 있게 되었다. 생성기는 모듈의 회전 제한, 입구와 출구 방향, 연결 위치, 배치 영역 겹침을 검사하면서 목표 개수까지 모듈을 순차적으로 연결한다.

현재 단계에서는 분기 없는 선형 구조를 생성한다. 이후에는 분기와 합류, 체크포인트 배치, 시작·종료 모듈 구분, 생성된 맵과 플레이어 진행 시스템 연결을 추가할 수 있는 기반이 마련되었다.
