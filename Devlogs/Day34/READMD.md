# 프로젝트 J 33일차 개발일지

## 개발 주제

생성 맵 연결성·이동 가능성 종합 검증

## 개발 목표

32일차에 구현한 절차적 모듈 맵 생성 결과를 대상으로 그래프 연결성, 연결 지점, 이동 가능 높이, 모듈 겹침을 한 번에 검사하는 종합 검증 시스템을 구축한다.

## 개발 내용

### 1. 생성 맵 종합 검사기 구현

생성이 끝난 맵의 구조적 문제를 한 번에 확인할 수 있도록 종합 검사기를 추가했다. 검사 결과에는 발견된 문제의 종류와 관련 모듈 정보가 기록되도록 구성했다.

주요 검사 항목은 다음과 같다.

- 생성 그래프의 모든 노드 도달 가능 여부
- 그래프 노드와 실제 생성 모듈의 대응 여부
- 그래프 간선과 연결 지점의 대응 여부
- 연결 지점 ID의 유효성
- 출구와 입구 역할의 일치 여부
- 동일 연결 지점의 중복 사용 여부
- 연결 방향과 크기의 일치 여부
- 연결 지점 월드 좌표의 일치 여부
- 플레이어가 이동할 수 없는 높이 차이 여부
- 모듈 Bounds의 3차원 겹침 여부
- 모듈 내부 이동 규격의 유효성

### 2. 검사 실패 유형 세분화

문제가 발생한 원인을 정확하게 확인할 수 있도록 검사 실패 유형을 구분했다.

| 실패 유형 | 의미 |
|---|---|
| `GraphNodeUnreachable` | 시작 노드에서 도달할 수 없는 노드 |
| `MissingModuleInstance` | 그래프 노드에 대응하는 모듈 누락 |
| `MissingGraphNode` | 생성 모듈에 대응하는 그래프 노드 누락 |
| `MissingGraphEdge` | 실제 연결에 대응하는 그래프 간선 누락 |
| `MissingConnection` | 지정된 연결 지점 ID 누락 |
| `InvalidConnectionRole` | 출구와 입구 역할 반대 |
| `ReusedConnection` | 동일 연결 지점 중복 사용 |
| `ConnectionDirectionMismatch` | 연결 방향 불일치 |
| `ConnectionSizeMismatch` | 연결부 너비 또는 높이 불일치 |
| `ConnectionPositionMismatch` | 연결 지점 위치 불일치 |
| `TraversalHeightExceeded` | 플레이어가 이동할 수 없는 높이 차이 |
| `ModuleOverlap` | 모듈 Bounds 겹침 |
| `InvalidModuleData` | 모듈 내부 이동 규격 오류 |

### 3. 절차적 생성기와 종합 검사 연동

맵 생성 완료 직후 종합 검사가 자동 실행되도록 생성기와 검사기를 연결했다. 검사에서 문제가 발견되면 해당 생성 결과를 정상 완료로 처리하지 않도록 성공 판정 기준을 강화했다.

정상 생성 결과는 다음 조건을 만족해야 한다.

- 생성 그래프 구성 완료
- 모듈 인스턴스 생성 완료
- 모든 노드 도달 가능
- 모든 연결 지점 정상 연결
- 이동 불가능한 높이 차이 없음
- 모듈 Bounds 겹침 없음
- 발견된 종합 검사 문제 0개

### 4. EditMode 테스트 추가

종합 검사기의 핵심 기능을 검증하기 위해 신규 EditMode 테스트 5개를 추가했다.

| 테스트 | 검증 내용 |
|---|---|
| `ValidConnectedMapPassesAllChecks` | 정상 연결 맵의 전체 검사 통과 |
| `DisconnectedMapReportsReachabilityFailure` | 끊어진 경로와 도달 불가능 노드 검출 |
| `MissingConnectionIdReportsExactFailure` | 존재하지 않는 연결 ID 검출 |
| `OverlappingModulesReportBoundsFailure` | 모듈 Bounds 겹침 검출 |
| `UnsafeHeightDifferenceReportsTraversalFailure` | 이동할 수 없는 높이 차이 검출 |

기존 `ProceduralMapGeneratorTests`에는 생성 직후 종합 검사 실행 여부, 검사 성공 여부, 발견 문제 0개 여부를 확인하는 검사가 추가됐다.

32일차 핵심 테스트 17개와 33일차 신규 테스트 5개를 합쳐 맵 생성 관련 핵심 테스트는 총 22개다.

## 작업 결과

- 절차적 생성 결과를 자동으로 검사하는 종합 검증 구조 완성
- 그래프와 실제 생성 모듈의 불일치 검출 가능
- 연결 위치·방향·크기·역할 오류 검출 가능
- 도달 불가능한 경로와 이동 불가능한 높이 차이 검출 가능
- 3차원 Bounds 기반 모듈 겹침 검출 가능
- 생성 성공 판정에 종합 검사 결과 반영
- 종합 검사기 신규 EditMode 테스트 5개 추가

- 그래프 노드 8개 생성
- 그래프 간선 8개 생성
- 종합 검사 문제 0개
- 모든 노드 도달 가능

- 이동 불가능한 높이 차이 없음

## 문제점 및 개선 방향

현재 생성 구조는 연결 안정성과 이동 가능성을 검사할 수 있지만, 모듈이 주로 수평으로 배치된다. 프로젝트의 최종 목표인 수직 상승형 진행을 구현하려면 다음 단계에서 입구와 출구의 Y 좌표 차이를 데이터로 관리하고, 상승 모듈을 제작해야 한다.
