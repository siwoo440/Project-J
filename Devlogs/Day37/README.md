## 37일차 : 플레이 가능 경로 검사 및 생성 디버그 시각화

### 개발 목표

36일차에 구현한 수직 분기·합류 맵을 대상으로 시작 지점부터 종료 지점까지 실제 이동 가능한 경로가 존재하는지 데이터 기반으로 검사한다. 왼쪽과 오른쪽 분기 경로를 각각 검증하고, 잘못된 구조의 원인과 위치를 Scene 뷰에서 확인할 수 있도록 디버그 시각화를 추가한다.

### 구현 내용

- 시작 노드부터 종료 노드까지의 전체 경로 탐색
- 왼쪽·오른쪽 분기 경로 개별 검증
- 도달할 수 없는 노드 및 막다른 경로 검출
- 순환 경로 및 복수 종료점 검출
- 경로 내부의 누락된 모듈 참조 검출
- 모듈 이동 조건과 수직 이동 구간 검증
- 최대 경로 수 초과 및 분기 누락 검출
- 경로 검사 결과 보고서 저장
- 검사 실패 노드와 연결선의 Scene 기즈모 표시
- 동일 시드에서 경로 순서와 결과가 재현되는지 검증

### 정상 분기 경로

수직 분기 맵은 다음 두 경로가 같은 종료 노드에 도달해야 한다.

```text
왼쪽 경로  : 0 → 1 → 2 → 4 → 6 → 7
오른쪽 경로: 0 → 1 → 3 → 5 → 6 → 7
```

### 생성 성공 조건 변경

기존 모듈 배치·연결·Bounds·높이 검사를 통과한 뒤 플레이 가능 경로 검사까지 성공해야 최종 생성 성공으로 처리하도록 조건을 강화했다.

```text
기존 생성 검사 성공
+ 플레이 가능 경로 검사 성공
= 최종 맵 생성 성공
```

### 경로 검사 보고서

`LastPlayableRouteReport`를 통해 다음 정보를 확인할 수 있도록 구성했다.

- 시작 노드와 종료 노드 번호
- 발견된 전체 경로 수
- 각 경로의 노드 순서
- 왼쪽·오른쪽 분기 포함 여부
- 문제 종류와 발생 이유
- 문제가 발생한 경로와 관련 노드

### 디버그 시각화

Scene 뷰의 기즈모에서 경로 상태를 색상으로 구분하도록 구성했다.

| 색상 | 의미 |
|---|---|
| 초록색 | 분기 전후 공통 노드 |
| 파란색 | 왼쪽 분기 노드 |
| 분홍색 | 오른쪽 분기 노드 |
| 청록색 선 | 정상 연결 경로 |
| 노란색 | 최종 종료 노드 |
| 빨간색 | 경로 검사 실패 위치 |

- 최대 경로 수 초과 검출
- 생성된 수직 분기 맵의 좌우 경로 확인
