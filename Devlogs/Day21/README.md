# Project J 개발 일지

---

## 21일차 : 기본 점프·중력·코요테 타임 및 점프 버퍼 통합

### 개발 목표

플레이어 이동 컨트롤러에 분산되어 있던 기본 점프, 중력, 코요테 타임, 점프 입력 버퍼 처리를 하나의 독립된 점프 제어기로 통합한다.

### 주요 구현 내용

- `PlayerJumpGravityController` 신규 구현
- 접지·상승·낙하 상태 구분
- 목표 점프 높이를 기준으로 초기 상승 속도 계산
- 지면을 벗어난 직후에도 짧은 시간 동안 점프할 수 있는 코요테 타임 적용
- 착지 직전에 누른 점프 입력을 보관하는 점프 버퍼 적용
- 접지 중력과 공중 중력 처리 통합
- 최대 낙하 속도 제한
- 천장 충돌 시 남은 상승 속도 제거
- 앉기 및 자세 전환 중 점프 입력 차단
- 부활 시 점프 상태와 관련 타이머 초기화

---

## 점프 처리 흐름

1. 현재 접지 상태 확인
2. 코요테 시간 갱신
3. 새로운 점프 입력 확인
4. 점프 입력 버퍼 갱신
5. 접지 또는 공중 중력 적용
6. 자세와 점프 가능 조건 확인
7. 점프 실행 또는 입력 유지
8. `CharacterController.Move()` 실행
9. 천장 충돌과 착지 결과 반영

---

## 점프 상태

| 상태 | 설명 |
|---|---|
| `Grounded` | 지면에 접촉한 상태 |
| `Rising` | 점프 후 상승 중인 상태 |
| `Falling` | 최고점을 지나 낙하 중인 상태 |

---

## 적용 수치

| 항목 | 값 |
|---|---:|
| 점프 높이 | `2.4m` |
| 중력 가속도 | `-25m/s²` |
| 최대 낙하 속도 | `35m/s` |
| 코요테 시간 | `0.12초` |
| 점프 입력 버퍼 | `0.12초` |

점프 초기 상승 속도는 목표 점프 높이와 중력 값을 이용해 계산한다.

```text
√(2 × 25 × 2.4) ≈ 10.95m/s
```

## 세부 구현 결과

### 기본 점프와 중력

- 목표 높이에 맞는 초기 상승 속도 적용
- 프레임 시간에 따른 중력 누적
- 상승 속도가 `0` 이하가 되면 낙하 상태로 전환
- 낙하 속도가 설정된 최대값을 넘지 않도록 제한
- 접지 상태에서는 안정적인 지면 접촉을 위한 수직 속도 적용

### 코요테 타임

- 지면을 벗어나면 `0.12초`의 허용 시간 시작
- 허용 시간 안에 입력된 점프 실행
- 허용 시간이 끝난 뒤에는 공중 점프 차단
- 점프가 실행되면 남은 코요테 시간 제거

### 점프 입력 버퍼

- 공중에서 누른 점프 입력을 최대 `0.12초` 동안 보관
- 보관 시간 안에 착지하면 즉시 점프 실행
- 시간이 만료된 입력은 자동 제거
- 앉기 및 자세 전환 중 발생한 입력은 보관하지 않음

### 충돌과 초기화

- 천장 충돌 시 상승 속도를 즉시 제거해 관통 방지
- 착지 결과를 다음 프레임의 점프 판정에 반영
- 부활 시 점프 상태를 `Grounded`로 복원
- 부활 시 수직 속도, 코요테 시간, 점프 버퍼 제거
