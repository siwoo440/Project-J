## 3. 주요 구현 내용

---
### 3.1 밀치기 입력 연결

- `PlayerInputReader`에 밀치기 액션 참조 추가
- 현재 프레임의 밀치기 시작 입력을 반환하는 `WasPushPressedThisFrame()` 추가
- 필수 입력 액션 누락 검사에 `Push` 포함

---
### 3.2 플레이어 밀치기 기능

- 플레이어 전방에 밀치기 판정 범위 생성
- 판정 시작 구체와 이미 겹친 대상을 `OverlapSphereNonAlloc()`으로 검사
- 전방 범위를 `SphereCastNonAlloc()`으로 검사
- 플레이어 자신의 충돌체를 판정 대상에서 제외
- 장애물보다 앞에 있는 가장 가까운 더미만 선택
- 대상 방향으로 수평 밀치기 속도 적용
- 밀치기 재사용 대기시간 1.2초 적용
- Scene 뷰에서 판정 범위를 확인할 수 있는 Gizmo 표시

---
### 3.3 밀치기 더미 상대

- `CharacterController` 기반 더미 이동 구현
- 밀치기 속도와 수평 감속 처리
- 중력과 최대 낙하 속도 처리
- 0.8초 연속 피격 면역 적용
- 추락 한계 아래로 떨어지면 최초 위치로 복귀
- 현재 높이, 최고 높이, 최고 높이 도달 시간 기록
- `DUMMY A`, `DUMMY B`, `DUMMY C` 3개 배치

---
### 3.4 경기 타이머와 순위

- 경기 제한 시간을 600초로 설정
- 플레이어 1명과 더미 3명을 포함한 4인 순위 구성
- 경기 중에는 현재 높이를 기준으로 실시간 순위 계산
- 경기 종료 시에는 최고 높이를 기준으로 최종 순위 계산
- 최고 높이가 같으면 먼저 도달한 참가자를 우선 처리
- 모든 비교 값이 같으면 고정 순서로 결과 안정화

---
### 3.5 HUD와 결과 화면

- 남은 시간을 `분:초` 형식으로 표시
- 현재 순위와 전체 참가자 수 표시
- 기존 높이, 최고 높이, 체크포인트, 스태미나 정보 유지
- 경기 종료 시 플레이어의 최종 순위 표시
- 전체 참가자의 최종 순위와 최고 높이 목록 표시

---
### 3.6 경기 종료 예외 처리

- 경기 종료 시 진행 중인 부활 코루틴 즉시 중단
- 경기 종료 이후 새로운 부활 요청 차단
- 비활성화된 플레이어 충돌체 복구
- 입력, 이동, 밀치기 컴포넌트 비활성화
- 부활 대기 중 경기가 종료되어도 조작이 다시 활성화되지 않도록 처리

## 6. 검토 결과

- 씬에 저장된 경기 시간이 `600초`로 정상 반영됨
- HUD와 경기 관리자 참조가 정상 연결됨
- 경기 관리자에 플레이어 입력, 이동, 부활, 밀치기 참조가 정상 연결됨
- 경기 관리자에 더미 3개가 정상 등록됨
- 밀치기 입력 메서드와 호출부가 일치함
- 시작 지점과 겹친 대상도 밀치기 판정에 포함됨
- 경기 종료 시 진행 중인 부활이 조작을 다시 활성화하는 문제 해결됨
- 저장소 정적 검토 기준으로 명백한 C# 참조 오류와 기능 누락 없음

Unity 에디터의 실제 컴파일과 플레이 모드 동작 여부는 저장소 내용만으로 확인할 수 없으므로 별도 실행 검증이 필요하다.

---
## 7. 플레이 테스트 확인 항목

- 경기 시작 시 HUD의 남은 시간이 `10:00`으로 표시되는지 확인
- 밀치기 입력 시 가까운 더미 한 개만 밀리는지 확인
- 더미와 밀치기 시작 구체가 겹친 상태에서도 판정되는지 확인
- 벽 뒤의 더미가 밀리지 않는지 확인
- 더미가 0.8초 동안 연속 밀치기에 면역인지 확인
- 더미 추락 후 최초 위치로 정상 복귀하는지 확인
- 현재 높이에 따라 실시간 순위가 변경되는지 확인
- 10분 종료 후 최고 높이 기준 최종 결과가 표시되는지 확인
- 부활 대기 중 경기가 종료되어도 조작이 다시 활성화되지 않는지 확인
- 경기 종료 후 이동, 점프, 밀치기가 모두 차단되는지 확인

14일차 작업은 밀치기 상호작용, 더미 상대, 10분 타이머, 높이 순위, 최종 결과 화면을 하나의 오프라인 경기 흐름으로 연결하는 단계다. 저장소 정적 검토 기준 구현과 참조 설정은 완료되었으며, Unity 에디터에서 컴파일과 플레이 테스트를 통과하면 14일차 개발을 최종 완료로 판단한다.
