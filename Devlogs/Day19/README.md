# Project J 개발 일지

---

## 19일차 : 달리기 취소 조건 및 스태미나 소모·회복 통합

### 개발 목표

달리기 판정과 스태미나 처리를 별도의 상태 제어기로 분리하고, 달리기 시작·취소·소모·회복 규칙을 일관되게 관리할 수 있도록 개선했다.

### 구현 내용

- 달리기 시작 조건 통합
- 달리기 취소 조건 통합
- 이동 중 스태미나 초당 소모 처리
- 달리기 종료 후 회복 대기 적용
- 회복 대기 종료 후 스태미나 자동 회복
- 스태미나 최댓값 제한
- 달리기 시작에 필요한 최소 스태미나 검사
- 스태미나 소진 시 달리기 강제 취소
- 소진 후 Shift 유지 상태의 자동 재시작 차단
- Shift 해제 후 재입력 시 달리기 재개
- 부활 시 달리기와 스태미나 상태 초기화

### 달리기 시작 조건

다음 조건을 모두 만족할 때 달리기가 시작된다.

- 달리기 입력 유지
- 이동 입력 존재
- 지상 접지 상태
- 서 있는 상태
- 플레이어 조작 가능 상태
- 최소 시작 스태미나 충족
- 소진 후 입력 해제 대기 상태가 아님

### 달리기 취소 조건

다음 상황에서는 달리기를 즉시 취소한다.

| 취소 원인 | 처리 내용 |
|---|---|
| Shift 해제 | 걷기 상태 전환 |
| 이동 입력 해제 | 달리기 종료 |
| 공중 진입 | 달리기 종료 |
| 앉기 시작 | 달리기 종료 |
| 스태미나 소진 | 달리기 강제 종료 및 재시작 차단 |
| 플레이어 조작 차단 | 달리기 종료 |

### 스태미나 규칙

| 항목 | 기본값 |
|---|---:|
| 최대 스태미나 | 100 |
| 초당 소비량 | 20 |
| 초당 회복량 | 25 |
| 회복 대기 시간 | 0.75초 |
| 달리기 시작 최소값 | 5 |

달리는 동안 스태미나를 지속해서 소모하며, 달리기가 끝난 뒤 0.75초가 지나면 회복을 시작한다. 스태미나가 0이 되면 달리기를 강제로 중단하고, Shift를 한 번 놓기 전까지 자동으로 다시 달리지 않도록 처리했다.
